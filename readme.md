Jobify - Job Portal

Jobify is a full-stack job portal application that allows users to create accounts, browse job postings, and apply for jobs. Recruiters can post job opportunities and manage applicants. The platform is built to provide a seamless and responsive experience for both job seekers and employers.

🚀 Features

User Authentication – Secure login and registration for both job seekers and recruiters.

Job Listings – Browse, search, and filter available job opportunities.

Post a Job – Recruiters can add, update, and delete job postings.

Apply for Jobs – Job seekers can apply to jobs directly through the portal.

Role-Based Access – Different dashboards and features for recruiters and job seekers.

Responsive UI – Fully responsive design using React and Tailwind CSS.

State Management – Handled with Redux for scalability.

⚙️ Installation & Setup
Clone the repository
git clone https://github.com/your-username/jobify.git
cd jobify

Backend Setup
cd backend
mvn clean install
mvn spring-boot:run

Frontend Setup
cd frontend
npm install
npm start

🌐 Usage

Open the app in your browser: http://localhost:3000

Backend runs on: http://localhost:8080
